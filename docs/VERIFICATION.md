# Чеклист проверки (без реальных сотрудников)

Выполнять по порядку — каждый следующий пункт опирается на то, что
предыдущий прошёл. Всё проверяется на листе **«Тест»** — лист «МП» трогать
не должно ничего.

## 0. Подготовка

- [ ] Backend задеплоен по `backend/SETUP.md`, `SHARED_SECRET` и
      `TARGET_SHEET_NAME=Тест` заданы в Script Properties.
- [ ] В `client/TimeTracker/ApiSettings.cs` подставлены реальные `ApiUrl` и
      `SharedToken` (те же значения, что в Script Properties).
- [ ] `dotnet build` в `client/` проходит без ошибок.

## 1. Backend в изоляции

```powershell
$url = "https://script.google.com/macros/s/XXXXX/exec"
Invoke-RestMethod -Uri $url -Method Get   # health-check, {"ok":true,...}
```

- [ ] Health-check возвращает `ok: true`.
- [ ] Тестовый `start` (см. `backend/SETUP.md`, раздел 4) создаёт строку на
      листе «Тест» со статусом «в процессе».
- [ ] Повторная отправка **того же** `sessionId` с `eventType: start` не
      создаёт вторую строку (идемпотентность).

## 2. Первый запуск клиента

- [ ] `dotnet run` из `client/TimeTracker` — форма запрашивает имя, после
      сохранения появляется иконка в трее (красная — «остановлено»).
- [ ] `Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run`
      показывает значение `TimeTracker`, указывающее на exe.

## 3. Старт/стоп кнопкой

- [ ] Нажать «Начать работу» → иконка зеленеет, тултип показывает
      «Работаю: 00:00:0X».
- [ ] Открыть `%AppData%\TimeTracker\data.db` (например, `sqlite3` CLI или
      DB Browser for SQLite) — есть строка `EventType='start'`.
- [ ] В течение ~20-30 секунд строка помечается `Synced=1`, на листе «Тест»
      появляется соответствующая открытая строка (Конец пусто).
- [ ] Нажать «Закончить работу» → иконка краснеет, на листе строка закрыта:
      `Конец` заполнен, `Часов` посчитаны верно, `Статус=кнопка`.

## 4. Офлайн-режим

- [ ] Отключить сеть (`Disable-NetAdapter -Name "Ethernet" -Confirm:$false`
      или авиарежим).
- [ ] Нажать «Начать работу» — событие пишется в `data.db`, но остаётся
      `Synced=0`; строка в таблице не появляется.
- [ ] Подождать пару минут (проверить, что интервал синка увеличивается —
      backoff), включить сеть обратно
      (`Enable-NetAdapter -Name "Ethernet" -Confirm:$false`).
- [ ] Без каких-либо действий пользователя событие само уходит на сервер в
      ближайшем цикле, строка появляется в таблице.

## 5. Восстановление после сбоя

- [ ] Нажать «Начать работу».
- [ ] Жёстко убить процесс: `Stop-Process -Name TimeTracker -Force`
      (эмулирует BSOD/отключение питания — `SessionEnding` не успевает
      сработать).
- [ ] Перезапустить клиента вручную (или перезагрузиться и дать сработать
      автозапуску).
- [ ] Приложение стартует в состоянии «остановлено» (не Running).
- [ ] В `data.db`/на листе «Тест» сессия закрыта со статусом
      `восстановлено-после-сбоя`, время окончания — примерно момент
      последнего heartbeat (не момент перезапуска).

## 6. Настоящее выключение/выход

- [ ] Нажать «Начать работу».
- [ ] Выполнить обычный «Завершение сеанса» / перезагрузку из меню Пуск.
- [ ] Войти обратно — автозапуск поднимает клиента.
- [ ] Сессия на листе «Тест» закрыта со статусом `выключение`, время
      окончания примерно соответствует моменту реального выключения.

## 7. Ключевая проверка "opt-in"

- [ ] Просто включить/перезагрузить компьютер, **не нажимая** «Начать
      работу» — ни в `data.db`, ни на листе «Тест» не появляется ни одной
      новой строки. Автозапуск сам по себе не создаёт сессию.

## 8. Переход на боевой лист

- [x] Все пункты выше пройдены.
- [x] В Script Properties `TARGET_SHEET_NAME` сменён с `Тест` на `Часы`
      (передеплоивать не понадобилось).
- [x] Лист «МП» за всё время проверки остался нетронутым.
